센서 입력, 좌표 변환, 경로계획, 차량 제어를 연결하는 주요 구성과 설정을 정리했습니다. 코드 링크는 [2025년 9월 20일 공개 커밋](https://github.com/Khusla/HLFMA_2025/tree/48406564072bd34c5d223b7e9fb8b05a2381fa11)을 기준으로 하며, 미션 확장과 하위 제어는 실차 개발 보관본을 함께 소개합니다.

## 공개 코드와 실차 개발 구성

| 항목 | 공개 코드 | 실차 개발 보관본 |
|---|---|---|
| 초기 방향 보정 | GPS 변위 1 m, 직진 경로, EKF yaw 오프셋 | `correctioning` 상태를 전달하고 보정 중 구동 명령을 조정 |
| 경로 | `/gps/centerline1`을 받아 전방 경로 계산 | 일반·대안 경로 선택, 경로 말단 대기, 전진·후진 전환 |
| 카메라 | YOLOv5 노드와 `detections_v5` 상태 처리 | YOLOv8 API 기반 노드와 `detections_v8` 상태 처리 |
| 신호등 | 신호등 상태 발행·구독 | 지정 위치 반경 안에서 Red·Yellow 상태에 정지 명령 적용 |
| LiDAR 전방 검출 | 거리 상한 2 m, 연속 검출 5회 | 거리 상한 3 m, 연속 검출 3회, 0° 경계 분리 판정 및 좌·우 검출기 |
| 하위 제어 | 시리얼 차량 명령 송신 | Arduino 구동 PWM과 포텐시오미터 기반 조향 위치 피드백 |
| 시뮬레이션 | ROS 노드 중심 구성 | Gazebo 차량 모델, 가상 센서, ROS 브리지와 위치 추정 설정 |

## 위치와 방향의 역할

GNSS 위치는 `navsat_transform_node`를 통해 평면 좌표로 변환합니다. CSV 경로도 같은 노드의 `FromLL` 서비스를 사용해 차량 위치와 같은 좌표 기준으로 옮깁니다.

EKF는 오도메트리 속도와 IMU 방향·회전 정보를 입력으로 사용합니다. 경로계획기는 GNSS 변환 위치와 EKF 방향을 받아 차량 기준 경로를 생성합니다. 출발 시에는 실제 GPS 이동 방향과 EKF yaw의 차이를 구해 경로계획에 적용할 방향 오프셋을 설정합니다.

| 설정·규약 | 값과 용도 |
|---|---|
| 초기 방향 정렬 | 시작점과 현재 GPS 위치의 직선 변위가 1 m에 도달하면 방향 오프셋 계산 |
| 경로 재샘플링 | 기본 간격 0.30 m로 경로점을 선형 보간 |
| 차량 기준 경로 축 | 오른쪽 +x, 전방 +y |
| 목표 방향 | `atan2(x_target, y_target)` |
| 조향 명령 | 중앙 0, 좌우 1~5단계 |
| 보정 방향 출력 | `/path_planner/yaw_corrected` |

## 경로에서 차량 명령까지

경로계획기는 경유점 통과와 횡방향 이탈을 관리하면서 전방 목표점을 선택합니다. 동작계획기는 목표점 방향을 조향 단계로 바꾸고, 구간별 주행 조건을 적용해 구동 명령을 생성합니다.

```text
s{조향 단계} f{전륜 구동 명령} r{후륜 구동 명령}
```

실차 보관본은 초기 방향 정렬 중 구동 명령을 80으로 설정하고, 정렬이 끝나면 기본 명령 120으로 전환합니다. 경로 진행 방향은 `reverse`, 초기화 상태는 `correctioning` 필드로 전달합니다. Arduino는 조향 단계를 포텐시오미터 목표값으로 매핑하고, 현재 위치와의 오차에 따라 조향 모터를 구동합니다.

## 구간별 미션 처리

- **신호등:** 지정한 신호등 위치의 반경과 카메라 검출 상태를 함께 사용해 Red·Yellow 정지 조건을 적용합니다.
- **LiDAR:** 거리·각도 범위와 연속 검출 횟수로 장애물 조건을 판정합니다. 지정 구간의 정지 미션은 상태 플래그로 처리합니다.
- **경로 전환:** 경로 끝에서 대기한 후 일반·대안 경로를 선택하고 전진·후진 상태를 전환합니다.
- **후진 제어:** 목표 유지 시간, 조향 단계 변화 제한, 후진 구동값을 별도로 적용합니다.

## 개발 환경 구성

실차 환경은 ROS 2 Humble, Python, 사용자 정의 메시지, GNSS·IMU·LiDAR·카메라 입력과 Arduino 시리얼 통신으로 구성했습니다. 실행 환경을 옮길 때에는 센서 장치명과 통신 속도, 경로 CSV·모델 파일 위치를 해당 차량의 구성에 맞게 설정합니다.

경로를 준비할 때에는 위도·경도 열 이름과 구분자를 맞춘 뒤 좌표 변환과 재샘플링을 적용합니다. RViz에서는 현재 위치, 보정 방향, 전방 경로를 함께 표시해 센서·경로·제어 상태를 살펴볼 수 있습니다.
