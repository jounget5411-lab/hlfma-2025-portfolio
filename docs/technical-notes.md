# 구현 범위와 재현 안내

[프로젝트 소개로 돌아가기](../README.md)

이 문서는 [HLFMA_2025의 검토 커밋](https://github.com/Khusla/HLFMA_2025/tree/48406564072bd34c5d223b7e9fb8b05a2381fa11)을 기준으로 작성했습니다. 소스 코드를 검토했으며, 차량·센서가 연결된 환경에서 빌드하거나 주행을 재현하지 않았습니다.

## 구현 범위

- EKF 설정의 입력은 엔코더 오도메트리와 IMU입니다. 경로 계획은 GNSS 변환 위치와 EKF 방향을 별도로 사용합니다.
- 경로 제어는 목표점 방향에 따른 단계 조향입니다. Pure Pursuit 곡률식 기반 제어기로 표현하지 않습니다.
- 신호등 인식 결과를 생성·구독하는 코드가 있습니다. 현재 제어 콜백에서는 상태를 저장하며, 주행 명령에 적용하는 분기는 확인되지 않습니다.
- LiDAR 정지는 지정한 위치 구간에서 세션당 한 번 발동하는 로직입니다. 상시 정지 기능으로 일반화하지 않습니다.
- 타이머 주기와 파라미터는 코드 설정값입니다. 처리 속도·위치 정확도·성공률 등의 측정 결과를 뜻하지 않습니다.

## 재현 전에 정리할 구성

| 항목 | 소스에서 확인한 상태 | 필요한 확인 |
|---|---|---|
| 환경 | 설치 스크립트가 ROS 2 Humble 패키지를 사용 | 실제 운영체제·드라이버·Python 패키지 조합 검증 |
| LiDAR 발행 | `LPFL` 이름을 사용하지만 대응 별칭 정의가 없음 | import 및 모듈 참조 수정 후 장비 검증 |
| LiDAR 각도 범위 | 340°~20° 설정과 index 교환 로직 | 0°를 지나는 검출 구간 의도와 실제 scan 좌표 확인 |
| 경로 launch | 노드 1~5를 선언하나 노드 2~5 및 CSV가 현재 트리에 없음 | 실제 사용하는 노드·경로로 실행 구성 정리 |
| LiDAR launch 설치 | 패키지 `setup.py`에 launch 파일 설치 항목 없음 | 설치 후 launch 탐색 경로 확인 |
| 시리얼 장치 | 오도메트리 수신·명령 송신 기본 장치는 같고 통신 속도는 다름 | 실제 장치 배치·통신 속도·접근 방식 확인 |
| 통합 실행 | 위치 관련 launch와 개별 노드가 분리됨 | 최종 사용 노드 집합과 시작 순서를 문서화 |
| 데이터 경로 | 개발 환경의 절대 경로가 포함됨 | CSV·로그·모델 경로를 실행 환경에 맞게 설정 |

이 항목들은 정적 검토 결과이며, 대회 당시 실제 사용한 설정이나 별도 실행 절차와 다를 수 있습니다. 정확한 재현 가이드는 해당 환경과 대조한 뒤 작성할 수 있습니다.
