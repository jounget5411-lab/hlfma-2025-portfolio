# Visual assets

| 파일 | 내용 |
|---|---|
| `hero.svg` / `hero.png` | 프로젝트 대표 이미지 |
| `architecture.svg` / `architecture.png` | 공개 코드의 센서 입력·경로계획·차량 제어 구조도 |

세 도식은 이 포트폴리오를 위해 제작했습니다. 편집용 SVG와 표시용 PNG를 함께 제공하며, SVG는 Malgun Gothic / Segoe UI / Arial 계열 폰트를 사용합니다.
