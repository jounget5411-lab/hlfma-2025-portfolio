# Visual assets

- `hero.svg` / `hero.png`: 프로젝트 소개용 개념 이미지
- `architecture.svg` / `architecture.png`: 코드에서 확인한 처리 구조
- `startup-alignment.png`: 제공된 상세 개발 기록의 초기 방향 정렬 도식

`hero`와 `architecture`의 도형·레이아웃은 이 포트폴리오를 위해 제작한 벡터 그래픽입니다. `architecture`는 공개된 2025년 9월 20일 커밋의 구성을 설명합니다. 외부 사진이나 생성된 하드웨어 사진은 포함하지 않습니다. 경로 모양, 격자 활성 패턴, 노드 배치는 설명용이며 실제 영상·주행 기록·실험 결과가 아닙니다.

`startup-alignment.png`는 개발 기록에 포함된 도식을 사용했습니다. 공개 코드와도 일치하는 GPS 이동벡터 기반 방향 보정 절차를 설명합니다. 그림의 각도 예는 가상의 계산 예이며 측정값이 아닙니다. GPS 변위 1 m와 누적 바퀴 이동거리를 구분합니다.

`hero`와 `architecture`는 수정 가능한 SVG와 표시용 PNG를 함께 제공합니다. 해당 SVG의 폰트는 Malgun Gothic / Segoe UI / Arial 계열을 사용합니다.
