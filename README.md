# HL FMA 2025 · GPS 경로 기반 자율주행

유아용 전동차를 개조해 센서를 탑재하고, 지도 경로와 차량의 위치·방향을 실제 조향·구동 명령으로 연결한 프로젝트입니다. 초기 방향 보정부터 경로 추종, 미션 상태 전환, Arduino 하위 제어까지 통합해 **HL FMA 2025 자율주행 경진대회 장려상**을 수상했습니다.

`ROS 2 Humble` · `Python` · `GNSS` · `IMU / EKF` · `LiDAR` · `Arduino` · `HENES-T870`

## 시스템 흐름

![공개 코드 기준의 GNSS·EKF 방향, 상대 경로, 차량 명령 흐름](assets/system-flow.svg)

GNSS 위치와 EKF 방향으로 차량 기준 경로를 만들고, 목표점 방향을 조향·구동 명령으로 바꿉니다. 실차 개발에서는 카메라 신호등 상태, 다중 경로 선택, 전진·후진 전환과 하위 조향 피드백을 추가했습니다. **공개 코드와 실차 보관본의 차이**는 [구현 구성 문서](docs/technical-notes.md)에 구분했습니다.

## 핵심 구현

### 1. 실제 이동으로 초기 방향 정렬

위치가 맞아도 초기 yaw가 어긋나면, 차량 앞의 경로가 옆에 있는 것처럼 계산됐습니다. 출발 후 **GPS 위치가 1 m 이동할 때의 벡터**를 방향 기준으로 삼고, EKF yaw와의 차이를 오프셋으로 저장했습니다. 이후 경로 계산에 같은 보정을 적용하고, 실차 보관본에서는 초기화 상태를 구동 계층에도 전달했습니다.

### 2. 지도 좌표를 조향 명령까지 연결

GNSS 위치와 CSV 경로에 같은 좌표 변환 기준을 적용했습니다. 차량 기준 축을 **오른쪽 +x, 전방 +y**로 정의하고, 목표 방향 계산과 조향 부호를 맞췄습니다. 상위 조향 단계를 Arduino의 포텐시오미터 목표값으로 연결해 기구의 실제 위치를 제어했습니다.

### 3. 미션 상태와 관측 경로 구성

실차 보관본에서 구간별 신호등·LiDAR 조건, 경로 끝 대기, 다음 경로 선택과 전진·후진 전환을 관리했습니다. 현재 위치·보정 방향·전방 경로를 함께 시각화해 **차량이 어떤 정보를 바탕으로 조향하는지** 확인할 수 있게 했습니다.
